Sintaxis Básicas

Fundamentos de HTML

HTML (HyperText Markup Language) es el componente estructor básico de cualquier página web. Funciona mediante un sistema de etiquetas.

1. Tipos de Sintaxis

  • Etiquetas con Cierre: Requieren una apertura y un cierre obligatorio.
  • Etiquetas Autoconclusivas: No envuelven texto, se cierran a sí mismas.
  • Atributos: Modificadores que van dentro de la etiqueta de apertura.
Elemento ¿Cómo se crea/inserta? Ejemplo de Código
Tablas Se crean con la etiqueta <table>. Usa <tr> para las filas, <th> para los encabezados y <td> para las celdas de datos. 
<table>
  <tr>
    <th>Título</th>
  </tr>
  <tr>
    <td>Dato</td>
  </tr>
</table>
Imágenes Se insertan con la etiqueta autoconclusiva <img>. Requiere el atributo src (ruta de la imagen) y se recomienda usar alt (texto alternativo). 
<img src="ruta/imagen.jpg" alt="Descripción" width="200">

FUNDAMENTOS DE MySQL

CREAR BD Y TABLAS

¿Cómo crear una Base de Datos en MySQL?

Para comenzar a trabajar en MySQL, el primer paso es crear el contenedor donde se almacenarán todas nuestras tablas e información. Esto se logra mediante sentencias de código SQL estructuradas.

Pasos Básicos:

  • Creación: Se utiliza el comando CREATE DATABASE seguido del nombre que deseas asignarle.
  • Selección: Antes de crear tablas, debes indicarle al sistema qué base de datos vas a usar con el comando USE.

Ejemplo de Código SQL:

-- 1. Crear la base de datos llamada 'mi_tienda'
CREATE DATABASE mi_tienda;

-- 2. Seleccionar la base de datos para empezar a usarla
USE mi_tienda;
